# The architecture page

`index.html` here is a browsable map of mneme-llm, made from the code itself. It starts at the whole package (your
application, `Mneme`, the parts that own each kind of row, the meaning and decision tiers, the SQLite store) and goes
in: a folder, then a file, where each class is a box around its methods (grouped by the file's `# ---- section ----`
comments), and finally one function, whose code shows in the pane on the right. **One exchange, end to end**
(`#/guide/exchange`) follows `aprompt` before a reply and `aobserve` after it through the real functions. Every box
can be clicked, a click inside a diagram keeps your zoom and place, and the search finds any file, class or
function. On a phone the diagram and the details are one at a time, with a Diagram / Details switch; going into a
function opens its code.

- `data.js` is generated by [`tools/architecture.py`](../../tools/architecture.py): Python's `ast` reads every file
  git tracks under `mneme_llm/`, `tests/` and `tools/`, and records each file's docstring, imports, classes,
  functions, which call which inside the file, and the source.
- **After every change to the code, run `python tools/architecture.py` and commit `data.js` with the change.**
  `tests/test_architecture.py` fails while the page is out of date.
- `site.js` draws what is this project's own: the top map (after [DESIGN.md](../DESIGN.md), "The shape") and the guide
  (after its section 3). Change it when the architecture changes.
- `app.js`, `diagram.js` and `style.css` are the viewer, the same as in DiscordStudyBot's architecture page: `app.js`
  decides what each level shows and fills the pane, the search and the trail; `diagram.js` lays the diagrams out with
  [ELK](https://eclipse.dev/elk/) (elkjs 0.9.3, loaded from a CDN) and draws them as SVG, with zooming and panning
  (scroll or pinch, drag, the − / % / + / Fit buttons, the keys + − 0 and the arrows); `style.css` holds the look,
  light and dark, and the phone layout.

**To read it locally**, open `index.html` in a browser (the diagrams need the internet for ELK), or serve the folder:
`python -m http.server -d docs/architecture`.

**On GitHub Pages:** in the repository's Settings → Pages, choose "Deploy from a branch", the branch `main` and the
folder `/docs`. The page is then at `https://rustcoleone.github.io/mneme-llm/architecture/` (`docs/index.html` sends
the site's root there; `docs/.nojekyll` serves the files as they are).
